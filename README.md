# 个人记忆系统交互 Demo

[在线体验](https://ranz-feng.github.io/personal-memory-lab/) · [源码](https://github.com/Ranz-Feng/personal-memory-lab)

一个无需登录、无需后端即可体验的个人记忆系统闭环原型。页面内置“下周三去成都出差”的脱敏场景，逐步展示记忆门控、多路召回、上下文组装、回答应用、提取分类与更新遗忘。

## 流程判断

个人记忆系统可以做成一个完整可体验的 Demo。关键不是只展示“存进向量库”，而是把一次记忆闭环拆成七个可见决策：

1. 会话触发：理解当前任务和记忆缺口。
2. 记忆门控：判断是否值得调用历史记忆。
3. 多路召回：从画像、对话、行为三层找到候选证据。
4. 上下文组装：处理冲突、预算和隐私边界。
5. 回答应用：把记忆转换成具体建议，并标注来源。
6. 提取分类：对话结束后判断哪些信息值得写入。
7. 更新遗忘：更新旧偏好、设置临时信息 TTL，并允许用户删除。

## 视觉与叙事

- 采用论文图示风格：白纸网格画布、近黑粗描边、有限填充色与轻微手绘不规则圆角。
- 参考 FigGenie 的配色原则：每张图只保留一个主强调色，灰色表示旧状态或低权重，红色只表达阻塞与风险。
- 当前页以琥珀色表示当前步骤与重点证据，浅蓝只用于预算中的查询信息，浅绿表示成功召回，浅红表示策略拦截或用户遗忘。
- 顶部用一条七节点流程链展示完整闭环，当前步骤自动居中并加粗描边。
- 每一步都包含 `FIG.` 编号、系统动作可视化、底部“图 N”图注和右侧 `NOTES` 讲解。
- 视觉语言参考论文插图，但不复刻外部参考图中的文字、水印或人物素材。

## Demo 内置数据

场景为“下周三去成都出差”。内置记忆包括：

- 画像记忆：常驻上海，出差偏好安静、交通方便的酒店。
- 对话记忆：上次住春熙路较吵，希望下次避开。
- 行为记忆：出差行程习惯预留 30 分钟缓冲。
- 低相关候选：喜欢手冲咖啡，用于展示过滤逻辑。
- 敏感字段：证件号、精确住址，用于展示召回前拦截。
- 新对话：以后酒店优先安静、不临街，用于展示偏好更新。

## 体验方式

访问 [在线体验](https://ranz-feng.github.io/personal-memory-lab/)，或直接用浏览器打开 `index.html`。页面不请求网络，不读取真实账号、文件或记忆。

可重点体验：

- 逐步骤查看每层系统动作与产品解释。
- 点击顶部流程链直接跳转，或使用“下一步”顺序体验。
- 在召回步骤切换候选记忆，观察上下文预算变化。
- 在回答步骤关闭记忆，对比个性化与通用结果。
- 在最后一步关闭长期记忆或删除单条偏好。
